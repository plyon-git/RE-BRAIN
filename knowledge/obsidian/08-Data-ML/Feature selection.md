# Feature selection

Features should be available at the decision time, relevant to the task, legally usable, and supported by the source.

## 101XVC workflow

- Define each feature and availability timestamp
- Remove target leakage and unsupported precision
- Review protected-class and proxy use
- Document missing-value treatment
