# Extraction quality

Extraction quality measures whether fields and evidence spans match the source, including units, signs, date precision, and entity scope.

## 101XVC workflow

- Use reviewed representative examples
- Measure precision and missing-field rate
- Test negative values and table-scale conversions
- Reject layout changes that invalidate assumptions
