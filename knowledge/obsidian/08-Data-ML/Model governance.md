# Model governance

Model governance assigns ownership, scope, version, validation, deployment rules, monitoring, and retirement criteria.

## 101XVC workflow

- Maintain model cards and approved use cases
- Record training data and configuration hashes
- Separate material approval from routine operation
- Provide a rules-based fallback and rollback procedure
