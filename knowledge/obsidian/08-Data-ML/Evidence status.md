# Evidence status

An evidence status distinguishes observed source facts, self-reported claims, verified settlement records, unresolved claims, and analyst estimates.

## 101XVC workflow

- Use an explicit allowed-status vocabulary
- Require evidence to upgrade a status
- Keep status separate from model confidence
- Do not let attractive economics override missing evidence
