# Model validation

Validation asks whether a model works for its intended use with representative data, clear metrics, and known failure boundaries.

## 101XVC workflow

- Compare with a simple baseline
- Use held-out examples and stress cases
- Review performance by geography and property type
- Document when manual review overrides predictions
