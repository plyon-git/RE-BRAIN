# Model calibration

Calibration compares predicted confidence or outcome distributions with observed results. A high similarity score is not automatically a probability.

## 101XVC workflow

- Define the event being predicted
- Use held-out observed outcomes
- Display reliability and error by segment
- Keep sparse segments and uncertainty visible
