# Offline operation

Offline operation means the deployed analysis and search use local code, stored records, and local model parameters after installation.

## 101XVC workflow

- Distinguish acquisition connectivity from inference independence
- Test with network access disabled
- Keep dependency and dataset versions
- Show when locally cached evidence is stale
