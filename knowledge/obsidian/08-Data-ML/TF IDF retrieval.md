# TF IDF retrieval

TF-IDF represents text by weighted token frequencies. Similarity retrieves documents sharing useful terms; it does not establish that a financial claim is true.

## 101XVC workflow

- Use consistent tokenization for corpus and query
- Keep document IDs and source metadata
- Evaluate real information needs and synonym failures
- Show matched passages with provenance
