# Zoning review

Zoning determines a local regulatory framework for land use and development. Parcel-specific overlays and exceptions matter.

## 101XVC workflow

- Record the governing jurisdiction and code version
- Verify permitted use, dimensional standards, and overlays
- Review nonconforming use and approval conditions
- Obtain written planning confirmation for material assumptions
