# County source registry

A county registry should identify the authoritative assessor, collector, recorder, GIS, courts, and downloadable record sources separately.

## 101XVC workflow

- Store jurisdiction-qualified agency names
- Record source format, update cadence, and access terms
- Test downloads and record actual status
- Keep unsupported and manual sources visible
