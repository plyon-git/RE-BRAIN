# Supply pipeline

A supply pipeline should separate proposed, entitled, permitted, under-construction, delivered, and leased units.

## 101XVC workflow

- Assign each project an evidence-based stage
- Avoid summing overlapping datasets
- Track expected delivery and delays
- Compare competitive supply with the actual product segment
