# Public records request

A targeted request describes existing records, custodians, date range, fields, and preferred format. Federal FOIA does not govern every local office.

## 101XVC workflow

- Check the applicable state or local public-records law
- Search existing downloads before requesting
- Use a narrow machine-readable request
- Track fees, response, exemptions, and appeal options
