# Cash on cash return

Cash-on-cash return compares a defined period's cash distribution or cash flow with invested cash. Definitions vary, so show both numerator and denominator.

## 101XVC workflow

- Include initial fees and equity-funded capital work
- Separate refinancing proceeds from recurring operations
- Specify treatment of reserve contributions
- Report the period and whether the result is before taxes
