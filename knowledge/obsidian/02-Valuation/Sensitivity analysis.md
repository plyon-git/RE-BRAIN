# Sensitivity analysis

Sensitivity isolates how outputs respond to changes in selected assumptions; it does not estimate the probability of those assumptions.

## 101XVC workflow

- Choose drivers tied to uncertain evidence
- Show units and base-case position
- Test interacting variables when material
- Identify the assumptions that change the investment decision
