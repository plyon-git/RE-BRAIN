# Exit value

For an income property, a simple exit value is exit-year NOI divided by exit cap rate before transaction costs.

## 101XVC workflow

- Apply the cap rate to the correct future year
- Subtract selling costs and debt repayment
- Test slower lease-up and higher cap rates
- Separate gross valuation from equity proceeds
