# NPV

Net present value discounts each expected cash flow using a chosen rate and subtracts initial investment. The rate is an assumption, not a guaranteed outcome.

## 101XVC workflow

- Document rate and cash-flow timing conventions
- Include terminal proceeds and selling expenses
- Stress both operating assumptions and discount rate
- Compare alternatives using consistent periods
