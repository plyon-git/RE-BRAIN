# Equitable interest disclosure

The marketed interest should be described accurately. Texas rules are a jurisdiction-specific reference rather than a nationwide rule.

## 101XVC workflow

- Verify current state and local requirements before deployment
- Disclose contractual rights without implying ownership of the fee interest
- Store the actual disclosure and delivery evidence
- Review advertisements when the transaction structure changes
