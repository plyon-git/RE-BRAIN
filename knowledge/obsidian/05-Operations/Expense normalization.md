# Expense normalization

Normalization distinguishes repeatable operating expenses from exceptional items while preserving transparent adjustments.

## 101XVC workflow

- Save the original ledger values
- Support each adjustment with evidence
- Reassess taxes and insurance for new ownership
- Avoid removing a recurring cost merely because it is inconvenient
