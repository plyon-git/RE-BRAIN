# Public records request template

| Section | Fields to complete |
|---|---|
| Custodian | Verified responsible public office and jurisdiction |
| Records | Existing record types, time range, field list |
| Format | CSV or existing electronic format preferred |
| Fees | Request estimate and state fee-limit preference |
| Response | Case number, dates, fees, exemptions, follow-up |
| Boundary | Use actual governing law; federal FOIA is not a default county statute |
