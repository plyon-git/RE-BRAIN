# Deal evidence template

| Section | Fields to complete |
|---|---|
| Asset and scope | Name, location, seller, percentage interest |
| Completion | Exact close date or disclosed period; completion source |
| Value | Gross price, whole-asset valuation, seller-share proceeds: separate fields |
| Costs | Original basis, acquisition costs, repairs, holding, financing, exit costs |
| Outcome | Accounting gain, economic gain, realized cash profit: separate labels |
| Return | Dated contributions and distributions; cash IRR only if complete |
| Limits | Missing fields, contradicted claims, later adjustments |
