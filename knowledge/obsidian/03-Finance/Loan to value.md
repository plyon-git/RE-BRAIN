# Loan to value

LTV compares debt with a defined asset value. A higher valuation can hide unchanged debt risk.

## 101XVC workflow

- Record appraised value, date, and property interest
- Separate current value from stabilized value
- Include senior and subordinate exposure when evaluating total leverage
- Stress value declines and refinance proceeds
