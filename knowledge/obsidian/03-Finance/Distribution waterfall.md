# Distribution waterfall

A waterfall allocates available distributions according to the executed agreement. A preferred return and return of capital are different concepts.

## 101XVC workflow

- Model contributions, priority distributions, catch-up, and promote tiers
- State simple versus compounded preference
- Separate tax distributions and fees
- Validate edge cases against the signed agreement
