# Independent underwriting platform

Independent underwriting performs local computation using owned records and local model artifacts. New source acquisition can still need connectivity.

## 101XVC workflow

- Use local inference and durable exportable storage
- Separate collector connectivity from model inference
- Keep access control, audit, backups, and restoration procedures
- Expose unsupported predictions as unavailable instead of generating a persuasive answer
